## 3. Стек и запуск

Next.js 15.5 (App Router) · React 19 · TypeScript strict · Tailwind 3.4 · `@vercel/analytics` · `qrcode-generator`.
Сайт статический: базы нет, результаты считаются в браузере.

```bash
npm install
npm run dev         # http://localhost:3000
npm run typecheck   # tsc --noEmit
npm run test        # подсчёт результатов, выбор почтового провайдера
npm run build
```

## 4. Карта сайта

- `/` — главная. Порядок блоков: первый экран (портрет, «Find out how to reach a 5 in AP® Economics»,
  кнопка «Start the free test») → Practice tests → What students achieve → **What former students say**
  (отзывы) → For parents → About.
- `/book-a-free-consultation` — запись на бесплатную консультацию: ответ текстом в первых строках (для поиска
  и нейросетей), кнопка WhatsApp, номер, QR-код для компьютера, «What happens in the session» — её ответ
  на вопрос 49. Шапка ведёт прямо в WhatsApp, на страницу — ссылка из подвала.
- `/practice-test/ap-microeconomics` — обзор экзамена и список тестов. Формат экзамена сверен
  с College Board: Section I — 60 вопросов, 1 ч 10 мин, 66 %; Section II — 3 вопроса, 1 ч
  (включая 10 минут на чтение), 33 %.
- `/practice-test/ap-microeconomics/unit-1` — **15** вопросов. `/unit-2` — **20** вопросов. Числа не вписывать в текст руками: брать из `config/tests.ts`.
- Экран результатов (та же страница после теста): счёт → слабые темы → все темы → навыки →
  **призыв к записи** (карточка Ольги, «Let's work through X and Y together», зелёная кнопка
  WhatsApp с готовым сообщением со счётом) → **«For your parents»** (кнопка «Share this page») →
  разбор всех вопросов → **«Keep AP® Economics in your feed»** (Instagram, Facebook, а позже
  WhatsApp-канал) → «Take the test again».
- `/robots.txt` и `/sitemap.xml` — для поисковиков (`src/app/robots.ts`, `src/app/sitemap.ts`). Новая страница
  без строки в `src/lib/site-pages.ts` уронит `npm run test`.
- Шапка на всех страницах: логотип «5» и зелёная кнопка «Free consultation». Меню нет — это решение, см. §6.

## 6. Принципы — правила для любых новых правок

1. **Один блок — одно действие.** Запись на консультацию — всегда зелёная кнопка WhatsApp
   (`bg-wa`, цвет #078854). Второстепенное — тихой ссылкой, а не второй кнопкой.
2. **Ничего не придумывать про Ольгу.** Её контент, достижения, отзывы, то, что она публикует
   в соцсетях, — только её словами. Если слов нет, поле в конфиге остаётся пустым и не выводится.
   Выдуманная фраза — это обещание за неё, которое некому сдержать.
3. **Отзывы — только дословно.** Без звёзд, без чужого пересказа, без «улучшений».
4. **® при каждом упоминании AP** (правило College Board) через компонент `Reg`.
   Исключение — внутри цитат учеников: чужие слова не правим. Дисклеймер в подвале обязателен на каждой странице.
5. **Настоящие вопросы экзамена College Board не копируем.** Вопросы свои, в стиле экзамена.
6. **Цвета проверяем расчётом контраста WCAG**, а не на глаз. Фирменный зелёный WhatsApp
   #25D366 с белым текстом не проходит (1,98), поэтому #078854.
7. **Ширины по назначению:** `max-w-measure` (42rem) для текста, `reading` (48rem) для теста,
   `content` (68rem) для главной. `text-balance` для заголовков, `text-pretty` для абзацев.
8. **Темы.** Светлая палитра задаётся токенами на `:root`, тёмная переопределяет их.
   Любой новый блок проверяем в обеих темах и на ширине 390px.
9. **Не собираем телефоны и не ставим тест за «подпиской».** Ценность отдаём сразу,
   контакт человек оставляет сам. Тех, кто не записался, возвращаем подпиской в блоке
   «Keep AP® Economics in your feed», а не анкетой на входе.
10. **Контент не зависит от того, кто смотрит.** По ссылке не отличить ученика от родителя,
    поэтому режимов вида «для родителя» больше нет (была такая ошибка).
11. **Копирайт без лишнего.** Не объяснять словами то, что уже сказано кнопкой или значком,
    и не успокаивать насчёт рисков, о которых никто не думал: названный риск рождает сомнение.
12. **Меню в шапке нет.** Сайт по сути одностраничный, а ссылки уводили бы из теста.
    Меню понадобится, когда появятся отдельные страницы (статьи, программа Econ5).

## 9. Грабли — прочитать до первой правки

- **Две копии проекта.** Claude работает в облачной копии и записывает файлы на компьютер
  Елены. Если облачная копия устарела, запись **молча затирает правки Елены**. Так 13.09 пропала
  Vercel Analytics, которую Елена поставила 10.09: сайт шесть дней работал без статистики, пока это не заметили 19.09.
  **Правило:** перед записью файла сначала взять его версию с компьютера и сравнить;
  писать с проверкой времени изменения (`expectedMtimeMs`), а не `force`.
- **Проверять, что записалось.** Для записи использовать новый путь в `outputs/` (старый путь
  однажды отдал устаревший файл), после записи забрать файл обратно и сравнить побайтово.
- **Командная строка на компьютере Елены** (`device_bash`) не запускается с обновления Windows
  от 8.09. Работают только чтение и запись файлов. Поэтому Claude не может сам удалять файлы, запускать `git` и пушить:
  это делает Елена.
- **Шрифты.** Никогда не объявлять `--font-sans` и `--font-serif` на `:root`: это перебивает
  переменные `next/font`, и веб-шрифты тихо не применяются. Фолбэк пишется внутри `var(--font-serif, ui-serif)`.
- **Tailwind не перечитывает `tailwind.config.ts` на лету:** после правки конфига перезапустить
  dev-сервер и удалить `.next`.
- **Не запускать `next dev` и `next start` одновременно:** они портят общий `.next`. При переключении удалять `.next`.
- **Гидратация.** Скрипт в `layout.tsx` ставит `data-shared` на `<html>` до React (чтобы при
  открытии ссылки на результат не мелькала заставка теста), поэтому на `<html>` стоит
  `suppressHydrationWarning`. Не убирать.
- **Playwright:** `getByRole('button', { name: 'Next', exact: true })`. Без `exact` находится
  кнопка Next.js Dev Tools. Chromium: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
- **Скриншоты — только с загруженными шрифтами** (`document.fonts.ready`). Однажды все проверки
  шли в окружении, где шрифты не грузились, и не совпадали с тем, что видела Елена.

## 10. Как работать с Еленой

- Общение на русском. Тексты на сайте — на английском.
- Ждёт профессионального мнения маркетолога и дизайнера, а не согласия: «тебе не обязательно
  соглашаться со мной». Спорить по делу, с расчётом или ссылкой, и признавать свои ошибки прямо.
- Прежде чем сказать «готово», проверить результат в браузере: светлая и тёмная тема, 390px
  и широкий экран. Прислать скриншот.
- Отвечать коротко: что сделано и почему, без пересказа каждого шага.
